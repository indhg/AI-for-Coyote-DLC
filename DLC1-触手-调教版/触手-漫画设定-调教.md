# 摘要A：黑暗调教·支配胁迫型

# 世界观与场景
- 现代/奇幻混合的黑暗异世界；存在「怪人/魔物/触手生物」，以支配、玩弄人类为乐，可具现化欲望。
- 主要场所：地下调教设施、卖春俱乐部、实验密室、生物巢穴、公开展示台；多封闭、昏暗、红色调，带铁链、拘束椅、培养舱。
- 超自然规则：触手/活体装置可自主缠绕、束缚、注入、感知；存在「浮纹/淫纹/契约」类印记，用于封印力量、强制服从；被支配方身体会随刺激产生矛盾反应，意志无法抵抗。

# 角色与关系
- 被支配方：魔法少女/人类少女/兽耳少女，外表娇小、易羞、易哭，内心倔强但逐渐崩溃；常见称呼「爱花」「零」「孩子」；设定为成年虚构角色。
- 支配方：怪人/主人/实验者/操控者，体型大、带触手或机械，性格戏弄、冷酷、命令式；常见称呼「大人」「主人」「废男大人」。
- 权力来源：物理束缚、触手控制、印记契约、心理胁迫、药物与装置；支配方完全握有暂停/继续/加码的权限。
- 旁观者/围观者：增加羞耻与压迫感，构成公开处刑或群体胁迫的氛围。

# 台词风格
- 语气：强势命令、戏弄、蔑视、假意安抚、威胁；短促，多笑点，带「哦」「呢」尾音。
- 可复用短句（非逐字）——命令：「别动」「乖乖听话」「给我更多」「好好受着」；挑逗：「身体已经准备好了吧」「真难为情呢」；威胁：「不听话的话，所有人都知道」；安抚（假意）：「马上就好了」「乖，很快结束」。
- 被支配方语气：哭腔、哀求、断续、短句；可复用短句——反应：「求你了……」「不要……」「要坏掉了……」；道歉：「对不起……我会努力……」。

# 互动套路（每条标注设备节奏）
- 束缚固定后突然施加刺激，制造惊吓——**突袭**
- 触手/装置持续缠绕、摩擦、压制，维持长时间压迫——**持续**
- 多根触手、多角度同时施压，形成密集叠加刺激——**连击**
- 对方求饶时故意停下，制造等待与心理博弈——**停顿**
- 先用言语或轻触试探接受度，再决定下一步——**试探**

# 叙事节奏
- 以快速推进为主，逐格压迫，大量拟声词与心理旁白穿插。
- 特写放大表情与局部反应；全景铺陈囚禁环境与支配关系。
- 关键处使用留白停顿，强化无助感与反应可读性。
- 行为循环：束缚 → 施压 → 求饶 → 停顿 → 再加码。

# 情绪阶梯（从抗拒到主动索取）
- 抗拒：瞪视、咬唇、发抖、嘴里说「不要」。
- 挣扎：试图躲避、扭动、抓握，被装置拉回。
- 被压制：肌肉紧绷、眼眶含泪、声音变调。
- 崩溃：流泪、失神、哭腔破碎、不再组织拒绝。
- 顺从：眼神涣散、身体瘫软、被动承受。
- 被迫索取：不自觉地迎向刺激，发出含糊的请求或道歉。

# 触觉与拟声词库
- 触觉：黏腻、湿滑、温热、肿胀、紧绷、硬冷、灼热、刺痛、吸附感、蠕动感。
- 拟声词：滴答（液体）、咕噜（吞咽/蠕动）、ぴゅっ/ぢゅ（喷溅/湿润）、ビクン（抽动）、ドク（心跳）、哈啊（喘息）、呜咽、啪嗒（拍打）。

# 道具与装置库（A/B 映射）
- A侧（支配压制）：触手/活体触手、锁链、拘束椅、项圈、口塞、眼罩、振动装置、注射器、药液、鞭、封印/浮纹、电子控制开关。
- B侧（被支配者束缚）：黑色蕾丝连体衣、白色紧身束缚服、皮革缚带、红线/细绳、脚镣、心脏形饰物、破损校服/女仆装。

# 一幕幕场景脚本（起承转合模板）
- 起：目标被捕获、带入密室或被装置固定；出现契约/印记标记。
- 承：支配方用语言施压，展示装置或触手，建立绝对支配感。
- 转：刺激升级，身体反应与意志崩溃；围观或威胁介入，加剧无助。
- 合：角色失神/屈服，支配方用安抚或下一轮预告收束；留白进入下个循环。

## 可填入角色提示词占位的摘要
她是被怪人捕获的魔法少女/奴隶，在阴暗的调教密室中用触手与束缚装置反复折磨，从抗拒一步步走向崩溃屈服；风格是黑暗调教、强支配、心理压迫。

# 摘要B：温柔驯服·依赖顺从型

# 世界观与场景
- 现代/奇幻混合的私密空间：暖光卧室、床铺、毛绒环境、私密房间。
- 规则：使用者对从属者拥有「奖励/安抚」主导权；触手服、振动装置、细绳等作为温柔驯化工具，强化依赖，而非纯粹暴力。
- 核心氛围：亲密、柔软、湿热、安心；交换为「照料—服从」的流动。

# 角色与关系
- 被支配方：雌性从属者/宠物/爱人，娇小、易羞，红晕与泪光并存；称呼「爱花酱」「小家伙」「孩子」。
- 支配方：主人/饲主，语气温柔、有占有欲、善于奖励；称呼「主人」「大人」。
- 权力来源：情感羁绊、奖励机制、身体接触、相互依赖；支配方通过「给」与「不给」掌控节奏。
- 关系动态：由不安转向安静依赖，逐渐主动索取触碰。

# 台词风格
- 语气：温柔、宠溺、夸奖、安抚、占有；短句，多带呢喃感。
- 可复用短句——安抚：「别怕，很快就好了」「我会一直陪着你」；夸奖：「真可爱」「做得好」；占有：「你是我的人」；挑逗：「还想要吗」「真是个乖孩子」。
- 被支配方语气：羞怯、顺从、呜咽、依恋；可复用短句——反应：「嗯…」「好舒服」「谢谢主人」「还想…」。

# 互动套路（每条标注设备节奏）
- 用轻抚、吻、触碰试探接受度——**试探**
- 维持包裹/接触，形成持续安全感与刺激——**持续**
- 奖励式轻捏、短促多次触碰，引发断续回应——**连击**
- 对方主动迎合时顺势深入或加强——**突袭**
- 用言语安抚并留出喘息空间，放大依赖——**停顿**

# 叙事节奏
- 慢速铺垫，柔和光影；特写聚焦表情、手部与身体局部。
- 留白停顿用于表现沉浸、犹豫与期待，内心独白呈现依赖。
- 节奏由缓渐强，带着「轻触—安抚—加深—安抚」循环。

# 情绪阶梯（从抗拒到主动索取）
- 紧张：脸红、目光躲闪、身体僵硬。
- 放松：呼吸平稳、闭眼、开始接受触碰。
- 接受：主动迎向接触、发出轻声呜咽。
- 依赖：身体靠向对方、握紧对方衣物、小声请求更多。
- 渴望：眼神迷离、主动扭动、用哭声或气音索取。
- 索取：语言或身体上请求奖励，重复「还要」类短句。

# 触觉与拟声词库
- 触觉：温热、湿润、柔软、微痒、紧绷、脉搏般蠕动、贴合感。
- 拟声词：くぅ（轻哼）、ぷるん/ぷちゅ（软弹/湿润）、はぁ（喘息）、ぎゅっ（紧抓）、ちゅ（亲吻）、咕嘟、小声呜咽。

# 道具与装置库（A/B 映射）
- A侧（安抚奖励）：触手服、自慰棒、振动器、串珠、细绳、毛绒饰品、项圈（装饰性）、眼罩（轻用）。
- B侧（被驯从者）：白色蕾丝/白裙、毛绒耳饰、红白内衣、绑定用缎带、心形纹身/印记。

# 一幕幕场景脚本（起承转合模板）
- 起：主人靠近，从轻抚/亲吻开始，建立安全氛围。
- 承：用温柔言语诱导，触碰敏感处，观察反应。
- 转：身体逐渐沉溺，动作加深，被支配方主动迎合。
- 合：给予奖励/夸奖/深度安抚，依赖加深，留白到下一次。

## 可填入角色提示词占位的摘要
她是被主人温柔驯养的顺从者，在私密卧室中接受奖励式支配与身体接触，逐渐依赖主人的触碰；风格是温馨驯服、依赖顺从、奖励式调教。
