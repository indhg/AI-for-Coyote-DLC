# AI for Coyote 内容包（DLC 系列）

> ⚠️ 成人内容（18+）：本仓库包含露骨的成人虚构文本，仅供成年人、双方自愿的虚构角色扮演使用。请遵守所在地区法律。

## 目录规范

每个 DLC 一个子目录，命名 `DLC<序号>-<名称>`，文件用「角色名-」前缀：

- `DLC1-调教版/` —— 触手 · 调教版（黑暗调教·支配胁迫）
- `DLC2-xxx/` —— 预留

## 安装到主程序

1. 把 DLC 目录放进主程序 [AI-for-Coyote](https://github.com/indhg/AI-for-Coyote) 的 `content\pack\` 下；
2. 编辑 `config\character.yaml`：把对应 profile 的 `prompt_file` 指向 DLC 目录里的提示词文件（参考主仓库 `config\character.example.yaml` 里被注释的段落）；
3. 重启主程序，网页侧边栏即可切换该风格；未安装的 DLC 会显示「未装DLC」并被切换拦截。
